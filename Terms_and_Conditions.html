PhoneKeyboardBridge — by Pixel Forge Studio

Last updated: September 2026

1. What this software does

PhoneKeyboardBridge lets a Windows PC receive keystrokes from an Android phone's web browser, either over a direct USB connection (USB tethering) or over a shared local Wi-Fi/LAN network. No app installation is required on the phone — the phone only needs to open a web page served locally by the desktop application.

2. Local-network use only

The pairing web page and keystroke connection are served only on your local network (or over USB) and are not exposed to the public internet. A PIN code and/or QR code is required to pair a phone with a PC. You are responsible for only sharing that PIN/QR code with a device you trust.

3. Data handling

Keystrokes typed on the paired phone are transmitted directly to the connected PC on your local network to be typed into whatever application is focused on that PC. PhoneKeyboardBridge does not upload, store, or transmit this keystroke data to Pixel Forge Studio or any third party.

4. User responsibility

  • You are responsible for enabling USB debugging/tethering or connecting to the correct Wi-Fi network as required by the connection method you choose.
  • You are responsible for keeping the pairing PIN/QR code private.
  • Do not use this software to input text into systems or accounts you are not authorized to access.

5. Automatic updates & assets

On first launch, the application downloads a small package of app assets (images/icons) from a public GitHub release over an internet connection. No personal data is included in or collected during this process.
